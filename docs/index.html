A few things
before you start.

Do I have to move my code?+

No. Open an existing local Git repository. Tasks can work in your current workspace or in their own Git worktrees.

Can several agents work at once?+

Yes. Run separate task agents concurrently, with a worktree for each task to keep their branch changes separate. You can coordinate tasks from a task chat or the Workspace chat.

What do I need to get started?+

A Mac, a local Git repository, and an API key for OpenRouter or another OpenAI-compatible provider. The current build workflow supports Apple Silicon and Intel Macs.

Can I use my ChatGPT subscription?+

Lotse requires a model-provider API key. ChatGPT subscription sign-in is not available. API usage is billed separately by your provider.

Is model usage included?+

You connect your own provider and API key. Model usage is billed by that provider under its own pricing and terms.

How do I stay in control of the changes?+

Inspect diffs, ask for revisions, and review each task against a selected base branch. Agent actions follow your configured approval settings. You can stop a task run and use the merge controls when you are ready.

Which version do the screenshots show?+

The screenshots show the current development build with sample project data. Downloads link to the latest published release, v0.1.2 at the time of these captures. The development build also adds a shared attention stack for pending questions and approvals, plus default agent roles for new tasks. These additions are not in v0.1.2.

Where does my data go?+

Tasks and conversations are stored locally. Prompts and context sent to your model provider or connected tools follow those services’ terms. Provider keys, GitHub tokens and MCP secrets are stored in local, unencrypted credential files; saved website logins use macOS Keychain.

Does GitHub Inbox sync my tasks?+

Import copies an issue or pull request into a linked local task. Later edits do not sync in either direction.

Getting started +
  1. Get the app.

    Choose Apple Silicon for an M-series Mac, or Intel for an Intel-based Mac. Open the DMG and drag Lotse to Applications.

  2. Connect your model.

    Add your API key for OpenRouter or an OpenAI-compatible provider. Model usage is billed by your provider.

  3. Open your repository.

    Choose a local Git project, create a task, and give your agent a clear place to start.
